# ADR-003：执行放沙箱，而不是同集群容器

## 状态
已采纳（2026-11）

## 背景与约束
- 会在目标仓库里跑测试，代码是**不可信输入**
- 本机开发，不能依赖自建 K8s
- 需要可复现（同一份代码跑两次结果一致）

## 选项
A. 本机 subprocess 直接跑
B. 本地 Docker 容器跑
C. 托管沙箱（e2b 这类）
D. 云上 K8s Job

## 决策
选 C（本地开发阶段用 A 兜底）。判据：不可信代码不能碰宿主环境；本机没有可用 K8s。

## 后果
- 正面：与宿主隔离；一次一销，无残留
- 负面：依赖网络与第三方可用性；冷启动有延迟；免费额度有限
- 缓解：本地保留 subprocess 兜底路径（仅对可信仓库启用）

## 如果重来
会把"执行器"抽象成一个接口再写第一行代码——现在两套执行路径是后补的抽象。
